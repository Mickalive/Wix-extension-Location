# Wix Bookings Advanced Rules

Private build repository for a native Wix marketplace extension that adds advanced availability and booking rules to Wix Bookings.

The product constitution lives in `MAIN_PROMPT.md`. Autonomous development runs through GitHub Actions and OpenCode/Ox agents. The accepted state is maintained on `lab/wix-rules`; candidate agents work in isolated cycle branches and an independent director decides what survives.

This repository is intentionally private during development.
