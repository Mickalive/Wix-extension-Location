# Dashboard Lane

Do not build until `docs/state.json.phase` is `build`.

Priority once build begins:
- create a native Wix dashboard configuration experience using the framework validated by reconnaissance;
- make location/service/time rules simple to understand;
- support weekly windows, split windows, date exceptions and limits as the domain API allows;
- show validation, loading, empty, error and save/apply states;
- preview/explain what rules will do before destructive changes;
- provide accessible keyboard-friendly controls;
- show a clear upgrade state when managed active Bookings locations exceed the purchased tier.

Do not invent platform behavior, bypass typed interfaces, or duplicate Wix's own location-directory/site-display functionality.
